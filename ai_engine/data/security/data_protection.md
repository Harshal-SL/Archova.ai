layer: security
topic: data-protection

Protect data at rest and in transit:
- TLS for all service-to-service communication
- encryption for sensitive columns where required
- strict audit logs for privileged operations

Application controls:
- input validation and parameterized SQL
- outbound allow-list for third-party calls
- rate limiting on authentication and write endpoints

Shared terms: PostgreSQL, integration webhooks, deployment WAF.
