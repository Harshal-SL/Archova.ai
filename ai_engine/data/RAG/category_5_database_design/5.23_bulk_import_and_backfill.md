# Bulk Import and Backfill


## chunk_id
- 5.23

## category
- database_design

## type
- data_pattern

## definition
- loading large datasets or recomputing derived data safely using batching, checkpoints, and idempotent writes.

## when_to_use
- migrating data from a legacy system
- backfilling new columns, indexes, or projections
- rebuilding read models after schema changes

## when_not_to_use
- when the dataset is small and an online migration is simpler
- when backfills would overload production without throttling controls

## decision_signals
- need: migrating data from a legacy system
- need: backfilling new columns, indexes, or projections
- willing to accept: can create load spikes and contention if not rate-limited

## advantages
- enables safe large-scale changes without full downtime
- supports resumability after failures

## disadvantages
- can create load spikes and contention if not rate-limited
- requires careful monitoring and rollback planning

## anti_patterns
- use this when the dataset is small and an online migration is simpler
- use this when backfills would overload production without throttling controls
- ignoring the downside that can create load spikes and contention if not rate-limited

## real_world_examples
- backfilling a new search index from the source of truth in batches
- recomputing daily aggregates after a bug fix
