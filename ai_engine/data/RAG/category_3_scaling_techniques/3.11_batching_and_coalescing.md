# Batching And Coalescing

## chunk_id
- 3.11


## category
- scaling_techniques

## type
- scaling_technique

## definition
- grouping multiple operations into fewer calls to reduce overhead and improve throughput.

## when_to_use
- high per-request overhead like network round trips or transaction commits
- pipelines where minor latency increases are acceptable
- write-heavy systems that benefit from bulk operations

## when_not_to_use
- latency-critical interactive paths where batching adds noticeable delay
- when batching increases tail latency due to large payloads

## decision_signals
- need: high per-request overhead like network round trips or transaction commits
- need: pipelines where minor latency increases are acceptable
- willing to accept: increases latency for items waiting in the batch

## advantages
- reduces per-operation overhead and improves throughput
- lowers pressure on databases and downstream services

## disadvantages
- increases latency for items waiting in the batch
- complicates error handling and partial failure semantics

## anti_patterns
- using this when latency-critical interactive paths where batching adds noticeable delay
- use this when batching increases tail latency due to large payloads
- ignoring the downside that increases latency for items waiting in the batch

## real_world_examples
- bulk inserting events to a database or data lake sink
- coalescing duplicate cache-miss requests into a single load
