# Search Engine For Catalog

## chunk_id
- 12.19


## category
- application_archetypes

## type
- application_archetype

## definition
- a search experience for a product catalog with relevance ranking, faceting, autocomplete, and fast response times.

## when_to_use
- large catalogs where database queries are too slow for discovery
- supporting faceted navigation and typo tolerance
- powering site search and category browsing

## when_not_to_use
- small catalogs where structured filters are sufficient
- when relevance ranking is unnecessary and exact matching is enough

## decision_signals
- need: large catalogs where database queries are too slow for discovery
- need: supporting faceted navigation and typo tolerance
- willing to accept: indexing pipelines add eventual consistency and operational complexity

## advantages
- improves discovery and conversion with relevance-based results
- offloads expensive queries from the primary database

## disadvantages
- indexing pipelines add eventual consistency and operational complexity
- relevance tuning requires iteration and evaluation sets

## anti_patterns
- using this when small catalogs where structured filters are sufficient
- use this when relevance ranking is unnecessary and exact matching is enough
- ignoring the downside that indexing pipelines add eventual consistency and operational complexity

## real_world_examples
- projecting catalog updates into a search index via events
- using autocomplete with prefix indexes and popularity signals
