# URL Shortener

## chunk_id
- 12.26


## category
- application_archetypes

## type
- application_archetype

## definition
- a service that maps short identifiers to long urls and redirects with high read volume, caching, and abuse prevention.

## when_to_use
- designing a read-heavy key-value service
- modeling caching, rate limiting, and hot key mitigation
- supporting analytics for clicks and referrers

## when_not_to_use
- low-volume internal tooling where a database table is enough
- systems that cannot tolerate redirect latency and dependency failures

## decision_signals
- need: designing a read-heavy key-value service
- need: modeling caching, rate limiting, and hot key mitigation
- willing to accept: abuse vectors (spam, phishing) require strong controls

## advantages
- simple core model (short_code -> target_url)
- demonstrates caching, replication, and hot key protection

## disadvantages
- abuse vectors (spam, phishing) require strong controls
- analytics collection can overload the redirect path if not decoupled

## anti_patterns
- using this when low-volume internal tooling where a database table is enough
- using this when systems that cannot tolerate redirect latency and dependency failures
- ignoring the downside that abuse vectors (spam, phishing) require strong controls

## real_world_examples
- cache-aside for short_code lookups with long ttl and invalidation
- asynchronous click tracking via events to avoid slowing redirects
