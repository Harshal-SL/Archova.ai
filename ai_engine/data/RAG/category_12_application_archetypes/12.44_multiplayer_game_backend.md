# Multiplayer Game Backend

## chunk_id
- 12.44


## category
- application_archetypes

## type
- application_archetype

## definition
- a backend for real-time multiplayer sessions requiring low latency, authoritative state, matchmaking, and anti-cheat controls.

## when_to_use
- session-based multiplayer with real-time state updates
- requiring region-based routing and latency optimization
- needing matchmaking, lobbies, and player identity

## when_not_to_use
- turn-based games with relaxed latency requirements
- single-player games with minimal backend state

## decision_signals
- need: session-based multiplayer with real-time state updates
- need: requiring region-based routing and latency optimization
- willing to accept: low latency requirements constrain architecture choices

## advantages
- clear need for authoritative state and deterministic simulation
- benefits from regional partitioning and stateful session servers

## disadvantages
- low latency requirements constrain architecture choices
- cheating, ddos, and abuse mitigation are ongoing challenges

## anti_patterns
- using this when turn-based games with relaxed latency requirements
- using this when single-player games with minimal backend state
- ignoring the downside that low latency requirements constrain architecture choices

## real_world_examples
- matchmaking service placing players into region-based sessions
- authoritative game servers publishing state snapshots to clients
