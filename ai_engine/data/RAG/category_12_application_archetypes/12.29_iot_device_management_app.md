# IoT Device Management App

## chunk_id
- 12.29


## category
- application_archetypes

## type
- application_archetype

## definition
- an application that provisions devices, manages identities and firmware, ingests telemetry, and applies policies at fleet scale.

## when_to_use
- managing large device fleets with security requirements
- needing command-and-control plus telemetry ingestion
- enforcing per-device and per-tenant quotas

## when_not_to_use
- small sensor deployments without remote management
- systems where devices cannot authenticate reliably

## decision_signals
- need: managing large device fleets with security requirements
- need: needing command-and-control plus telemetry ingestion
- willing to accept: device security and credential rotation are challenging

## advantages
- clear boundaries between control plane and data plane
- supports scalable ingestion with streaming patterns

## disadvantages
- device security and credential rotation are challenging
- intermittent connectivity and lifecycle management add complexity

## anti_patterns
- using this when small sensor deployments without remote management
- using this when systems where devices cannot authenticate reliably
- ignoring the downside that device security and credential rotation are challenging

## real_world_examples
- device provisioning with certificates and rotateable secrets
- firmware rollout with staged deployment and rollback
