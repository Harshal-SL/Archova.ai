# Ad Tech Bidding System

## chunk_id
- 12.43


## category
- application_archetypes

## type
- application_archetype

## definition
- a low-latency system that evaluates ad requests, runs auctions, and returns bids within strict time budgets while tracking outcomes.

## when_to_use
- designing ultra-low-latency decisioning services
- modeling timeouts, fallbacks, and partial results under load
- handling massive request volume and cost constraints

## when_not_to_use
- systems without millisecond latency requirements
- workloads where batch decisions are acceptable

## decision_signals
- need: designing ultra-low-latency decisioning services
- need: modeling timeouts, fallbacks, and partial results under load
- willing to accept: high scale amplifies cost and operational complexity

## advantages
- forces disciplined latency budgets and timeout handling
- highlights caching and precomputation strategies for decisioning

## disadvantages
- high scale amplifies cost and operational complexity
- strict latency can reduce model sophistication and observability detail

## anti_patterns
- using this when systems without millisecond latency requirements
- using this when workloads where batch decisions are acceptable
- ignoring the downside that high scale amplifies cost and operational complexity

## real_world_examples
- precomputing campaign eligibility sets and caching them in memory
- enforcing hard timeouts and returning best-effort bids
