# ML Inference Service

## chunk_id
- 12.31


## category
- application_archetypes

## type
- application_archetype

## definition
- a service that serves machine learning models for real-time predictions with latency, throughput, and monitoring requirements.

## when_to_use
- ranking, personalization, classification, and anomaly scoring
- needing model versioning and controlled rollouts
- monitoring drift, bias, and performance regressions

## when_not_to_use
- purely offline model usage where batch scoring suffices
- applications that can use third-party inference without custom logic

## decision_signals
- need: ranking, personalization, classification, and anomaly scoring
- need: needing model versioning and controlled rollouts
- willing to accept: operational complexity for model monitoring and scaling

## advantages
- encapsulates model lifecycle and deployment practices
- supports canaries and a/b testing for model changes

## disadvantages
- operational complexity for model monitoring and scaling
- data drift can degrade accuracy without obvious failures

## anti_patterns
- using this when purely offline model usage where batch scoring suffices
- using this when applications that can use third-party inference without custom logic
- ignoring the downside that operational complexity for model monitoring and scaling

## real_world_examples
- real-time fraud scoring at checkout
- recommendation ranking with model rollouts and guardrail metrics
