# Workflow Automation Platform

## chunk_id
- 12.46


## category
- application_archetypes

## type
- application_archetype

## definition
- a platform that orchestrates multi-step workflows across services using triggers, actions, retries, and human approvals.

## when_to_use
- integrating many systems with configurable automation rules
- building long-running processes with checkpoints and retries
- supporting auditability and user-configured flows

## when_not_to_use
- simple linear processes that can be handled in one service
- workflows requiring strict immediate consistency across systems

## decision_signals
- long-running workflows (> minutes) with retries and checkpoints
- 3+ external systems integrated with conditional branching
- need auditability for automated actions (compliance or ops)

## advantages
- standardizes orchestration, retries, and observability for workflows
- enables non-engineers to configure automation safely

## disadvantages
- state management for long-running workflows is complex
- misconfigured automations can cause loops and excessive load

## anti_patterns
- building a workflow engine when a simple queue and worker is sufficient
- allowing unbounded retries that create loops and runaway load
- storing workflow state only in memory without durable checkpoints

## real_world_examples
- onboarding workflows spanning identity, provisioning, billing, and email
- approval-based changes requiring audit logs and rollback steps
