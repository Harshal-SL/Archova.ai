# Multitenant SaaS Crm

## chunk_id
- 12.50


## category
- application_archetypes

## type
- application_archetype

## definition
- a customer relationship management platform offered as saas with tenant isolation, configurable schemas, and role-based access.

## when_to_use
- modeling multi-tenant data access and customization
- designing per-tenant quotas, billing, and feature flags
- supporting integrations and exports with security controls

## when_not_to_use
- single-tenant enterprise deployments with dedicated infrastructure
- products without tenant-specific access controls or customization

## decision_signals
- need: modeling multi-tenant data access and customization
- need: designing per-tenant quotas, billing, and feature flags
- willing to accept: tenant customization can drive schema complexity and performance tradeoffs

## advantages
- strong reference for tenant isolation and authorization patterns
- enables efficient shared infrastructure and operational scaling

## disadvantages
- tenant customization can drive schema complexity and performance tradeoffs
- cross-tenant bugs are high impact and require rigorous testing

## anti_patterns
- using this when single-tenant enterprise deployments with dedicated infrastructure
- using this when products without tenant-specific access controls or customization
- ignoring the downside that tenant customization can drive schema complexity and performance tradeoffs

## real_world_examples
- per-tenant role models and field-level permissions
- export workflows with auditing, throttling, and tenant-scoped encryption keys
