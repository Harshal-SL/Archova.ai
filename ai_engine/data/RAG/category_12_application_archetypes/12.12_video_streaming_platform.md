# Video Streaming Platform

## chunk_id
- 12.12


## category
- application_archetypes

## type
- application_archetype

## definition
- a system that ingests video, transcodes into multiple bitrates, stores content, and serves it globally with low buffering.

## when_to_use
- designing media pipelines and global content delivery
- planning storage and bandwidth cost controls
- handling large file uploads and asynchronous processing

## when_not_to_use
- simple file hosting without adaptive streaming
- small audiences where global cdn complexity is unnecessary

## decision_signals
- need: designing media pipelines and global content delivery
- need: planning storage and bandwidth cost controls
- willing to accept: heavy compute cost for transcoding and storage

## advantages
- strong separation between ingest, processing, and delivery
- benefits from cdns, object storage, and async work queues

## disadvantages
- heavy compute cost for transcoding and storage
- complex drm, licensing, and regional restrictions

## anti_patterns
- using this when simple file hosting without adaptive streaming
- using this when small audiences where global cdn complexity is unnecessary
- ignoring the downside that heavy compute cost for transcoding and storage

## real_world_examples
- queue-based transcoding workers producing hls/dash renditions
- serving segments via cdn with cache-friendly immutable urls
