# Search And Discovery App

## chunk_id
- 12.34


## category
- application_archetypes

## type
- application_archetype

## definition
- an application where search, filtering, ranking, and exploration are core user experiences, often requiring dedicated indexing.

## when_to_use
- large catalogs, knowledge bases, and document stores
- needing faceting, autocomplete, and relevance tuning
- supporting multi-field search with performance requirements

## when_not_to_use
- small datasets where simple database queries are sufficient
- apps where users navigate primarily through fixed hierarchies

## decision_signals
- need: large catalogs, knowledge bases, and document stores
- need: needing faceting, autocomplete, and relevance tuning
- willing to accept: indexing pipelines add eventual consistency and operational overhead

## advantages
- dedicated search indexes improve latency and relevance
- supports flexible exploration and discovery features

## disadvantages
- indexing pipelines add eventual consistency and operational overhead
- relevance tuning requires data and iterative evaluation

## anti_patterns
- using this when small datasets where simple database queries are sufficient
- using this when apps where users navigate primarily through fixed hierarchies
- ignoring the downside that indexing pipelines add eventual consistency and operational overhead

## real_world_examples
- product discovery with faceting and typo tolerance
- enterprise document search with permissions filtering
