# Streaming Analytics App

## chunk_id
- 12.20


## category
- application_archetypes

## type
- application_archetype

## definition
- an application that processes continuous event streams to compute aggregations, detect anomalies, and trigger actions in near real time.

## when_to_use
- real-time monitoring, fraud signals, and operational alerting
- high-volume telemetry and clickstream processing
- needing low-latency insights and triggers

## when_not_to_use
- batch reporting with relaxed freshness requirements
- low event volume where simple scheduled jobs suffice

## decision_signals
- need: real-time monitoring, fraud signals, and operational alerting
- need: high-volume telemetry and clickstream processing
- willing to accept: stateful stream processing is complex to operate

## advantages
- provides near-real-time visibility and responses
- supports windowed computations and continuous detection

## disadvantages
- stateful stream processing is complex to operate
- exactly-once semantics are difficult; idempotency is often required

## anti_patterns
- using this when batch reporting with relaxed freshness requirements
- using this when low event volume where simple scheduled jobs suffice
- ignoring the downside that stateful stream processing is complex to operate

## real_world_examples
- anomaly detection on login events with streaming aggregations
- real-time dashboards for service metrics and business kpis
