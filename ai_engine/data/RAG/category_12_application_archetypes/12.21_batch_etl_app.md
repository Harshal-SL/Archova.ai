# Batch ETL App

## chunk_id
- 12.21


## category
- application_archetypes

## type
- application_archetype

## definition
- an application that extracts data from sources, transforms it on schedules, and loads curated outputs for reporting and downstream use.

## when_to_use
- nightly pipelines and periodic reconciliation
- large transformations that are too expensive for real-time processing
- building curated datasets with repeatable jobs

## when_not_to_use
- use cases requiring real-time insights and triggers
- workloads with continuously changing upstream data requiring streaming

## decision_signals
- need: nightly pipelines and periodic reconciliation
- need: large transformations that are too expensive for real-time processing
- willing to accept: data is stale between runs

## advantages
- simpler operational model than continuous streaming
- easier to reason about completeness per batch

## disadvantages
- data is stale between runs
- backfills and reprocessing can be expensive

## anti_patterns
- using this when use cases requiring real-time insights and triggers
- using this when workloads with continuously changing upstream data requiring streaming
- ignoring the downside that data is stale between runs

## real_world_examples
- nightly sales aggregation and customer segmentation updates
- periodic reconciliation of processor reports to internal ledgers
