# Internal Admin Tool

## chunk_id
- 12.13


## category
- application_archetypes

## type
- application_archetype

## definition
- an internal-facing application for operations teams to manage data, users, configurations, and support actions.

## when_to_use
- needing operational controls and customer support workflows
- managing feature flags, configs, and manual interventions
- enabling data corrections with approvals and auditing

## when_not_to_use
- public-facing consumer experiences
- systems where admin actions cannot be securely governed and audited

## decision_signals
- need: needing operational controls and customer support workflows
- need: managing feature flags, configs, and manual interventions
- willing to accept: high-risk surface area if authorization is weak

## advantages
- accelerates operations and reduces engineering toil
- centralizes privileged actions with consistent auditing

## disadvantages
- high-risk surface area if authorization is weak
- can become a dumping ground for ad hoc actions without governance

## anti_patterns
- using this when public-facing consumer experiences
- using this when systems where admin actions cannot be securely governed and audited
- ignoring the downside that high-risk surface area if authorization is weak

## real_world_examples
- support console for account recovery and refunds
- admin panels for content moderation and feature flag management
