# Fraud Detection Pipeline

## chunk_id
- 12.18


## category
- application_archetypes

## type
- application_archetype

## definition
- a near-real-time pipeline that scores transactions and user actions to detect abuse while minimizing false positives.

## when_to_use
- protecting payments, account creation, and promotions
- combining streaming signals with batch model training
- building explainable decision and review workflows

## when_not_to_use
- low-risk systems where manual review is sufficient
- environments without quality labeled data and monitoring

## decision_signals
- need: protecting payments, account creation, and promotions
- need: combining streaming signals with batch model training
- willing to accept: model drift and bias require continuous monitoring

## advantages
- improves business safety and reduces losses
- leverages event streaming and feature stores effectively

## disadvantages
- model drift and bias require continuous monitoring
- false positives can harm legitimate users and conversion

## anti_patterns
- using this when low-risk systems where manual review is sufficient
- using this when environments without quality labeled data and monitoring
- ignoring the downside that model drift and bias require continuous monitoring

## real_world_examples
- scoring checkout events in real time and routing high-risk cases to review
- training models nightly and deploying thresholds via feature flags
