# RAG Knowledge Assistant

## chunk_id
- 12.36


## category
- application_archetypes

## type
- application_archetype

## definition
- an application that answers questions using retrieval-augmented generation by indexing documents and grounding responses in retrieved context.

## when_to_use
- enterprise q&a over internal docs and policies
- chat assistants that must cite and follow a source corpus
- improving accuracy over pure llm generation

## when_not_to_use
- tasks needing exact computation where deterministic logic is required
- domains where no trusted documents exist to ground answers

## decision_signals
- need: enterprise q&a over internal docs and policies
- need: chat assistants that must cite and follow a source corpus
- willing to accept: quality depends on chunking, embeddings, and retrieval tuning

## advantages
- reduces hallucinations by grounding in retrieved chunks
- supports continuous updates by reindexing the corpus

## disadvantages
- quality depends on chunking, embeddings, and retrieval tuning
- can leak sensitive data if access control is not enforced at retrieval

## anti_patterns
- using this when tasks needing exact computation where deterministic logic is required
- using this when domains where no trusted documents exist to ground answers
- ignoring the downside that quality depends on chunking, embeddings, and retrieval tuning

## real_world_examples
- helpdesk assistant using product docs and runbooks
- compliance assistant answering from policies with citations
