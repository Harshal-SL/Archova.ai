# File Storage And Sharing

## chunk_id
- 12.35


## category
- application_archetypes

## type
- application_archetype

## definition
- a system that stores user files, manages sharing permissions, supports versioning, and serves downloads efficiently and securely.

## when_to_use
- designing object storage backed applications
- handling large uploads/downloads with access control
- implementing link sharing, previews, and collaboration features

## when_not_to_use
- small file attachments where storing in a database is acceptable
- systems without sharing or permissions requirements

## decision_signals
- need: designing object storage backed applications
- need: handling large uploads/downloads with access control
- willing to accept: permissions and link sharing are common sources of security bugs

## advantages
- scales well using object storage and cdn for distribution
- supports durable versioning and audit of changes

## disadvantages
- permissions and link sharing are common sources of security bugs
- metadata and search across files require additional indexing

## anti_patterns
- using this when small file attachments where storing in a database is acceptable
- using this when systems without sharing or permissions requirements
- ignoring the downside that permissions and link sharing are common sources of security bugs

## real_world_examples
- pre-signed urls for uploads and downloads with short expiry
- per-file acl enforcement and share links with revocation
