# Cache Compression


## chunk_id
- 4.20

## category
- caching_strategies

## type
- caching_strategy

## definition
- compressing cached values to reduce memory usage and network bandwidth at the cost of cpu for compression and decompression.

## when_to_use
- large cached payloads that cause memory pressure
- high network costs between app and cache clusters
- improving cache hit rate by fitting more entries into memory

## when_not_to_use
- very small values where compression overhead dominates
- cpu-constrained services where decompression increases latency

## decision_signals
- need: large cached payloads that cause memory pressure
- need: high network costs between app and cache clusters
- willing to accept: adds cpu overhead and can increase tail latency

## advantages
- increases effective cache capacity and reduces eviction rate
- lowers network bandwidth for cache gets and sets

## disadvantages
- adds cpu overhead and can increase tail latency
- requires careful choice of compression algorithm and thresholds

## anti_patterns
- using this when very small values where compression overhead dominates
- using this when cpu-constrained services where decompression increases latency
- ignoring the downside that adds cpu overhead and can increase tail latency

## real_world_examples
- compressing json blobs stored in redis
- compressing large response fragments cached at the edge
