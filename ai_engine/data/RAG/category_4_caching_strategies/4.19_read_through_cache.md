# Read-Through Cache


## chunk_id
- 4.19

## category
- caching_strategies

## type
- caching_strategy

## definition
- a strategy where a cache layer automatically loads data from the backing store on a miss via a cache loader.

## when_to_use
- centralizing cache population logic across many callers
- enforcing consistent ttl and load behavior across services
- simplifying application code by delegating fetch to the cache layer

## when_not_to_use
- when cache loader failures would tightly couple cache to the database
- when business logic is needed to compute values rather than fetch them

## decision_signals
- need: centralizing cache population logic across many callers
- need: enforcing consistent ttl and load behavior across services
- willing to accept: loader becomes a critical path and needs strong timeouts and fallbacks

## advantages
- standardizes cache loading behavior and reduces duplicated code
- can improve consistency in ttl and cache population

## disadvantages
- loader becomes a critical path and needs strong timeouts and fallbacks
- can increase coupling between cache infrastructure and data access

## anti_patterns
- use this when cache loader failures would tightly couple cache to the database
- use this when business logic is needed to compute values rather than fetch them
- ignoring the downside that loader becomes a critical path and needs strong timeouts and fallbacks

## real_world_examples
- caching library that fetches from database on miss automatically
- edge cache layer that fetches from origin and stores response
