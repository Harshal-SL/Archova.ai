# Load Balancer


## chunk_id
- 7.1

## category
- infrastructure_components

## type
- infrastructure_component

## definition
- a network component that distributes incoming traffic across multiple backend instances to improve availability and throughput.

## when_to_use
- scaling stateless services horizontally
- improving resilience by removing single-instance dependency
- enabling zero-downtime deploys via draining and health checks

## when_not_to_use
- single-instance systems where availability is not required
- stateful backends without session strategy or partitioning

## decision_signals
- need: scaling stateless services horizontally
- need: improving resilience by removing single-instance dependency
- willing to accept: adds another component to operate and secure

## advantages
- increases capacity and resilience with redundancy
- enables traffic management via health checks and routing

## disadvantages
- adds another component to operate and secure
- misconfiguration can cause outages or uneven traffic distribution

## anti_patterns
- using this when single-instance systems where availability is not required
- using this when stateful backends without session strategy or partitioning
- ignoring the downside that adds another component to operate and secure

## real_world_examples
- distributing api traffic across multiple web servers
- routing to the closest healthy region for lower latency
