# Search Service


## chunk_id
- 7.23

## category
- infrastructure_components

## type
- infrastructure_component

## definition
- a dedicated system that builds indexes and serves relevance-based queries for text and structured search use cases.

## when_to_use
- full-text search, autocomplete, and faceted navigation
- querying large datasets where database queries are too slow for discovery
- ranking and relevance scoring requirements

## when_not_to_use
- simple key lookups and exact filters that the primary database handles well
- when search requirements are minimal and do not justify extra infrastructure

## decision_signals
- need: full-text search, autocomplete, and faceted navigation
- need: querying large datasets where database queries are too slow for discovery
- willing to accept: introduces an indexing pipeline and eventual consistency

## advantages
- provides fast search and relevance tuning tools
- offloads expensive search queries from the primary database

## disadvantages
- introduces an indexing pipeline and eventual consistency
- requires operational management of indexes, shards, and analyzers

## anti_patterns
- using this when simple key lookups and exact filters that the primary database handles well
- use this when search requirements are minimal and do not justify extra infrastructure
- ignoring the downside that introduces an indexing pipeline and eventual consistency

## real_world_examples
- indexing a product catalog for autocomplete and faceted filtering
- maintaining a document index for customer support ticket search
