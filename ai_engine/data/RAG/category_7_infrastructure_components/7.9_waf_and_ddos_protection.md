# WAF and DDoS Protection


## chunk_id
- 7.9

## category
- infrastructure_components

## type
- infrastructure_component

## definition
- edge defenses that filter malicious traffic and absorb volumetric attacks to protect applications and availability.

## when_to_use
- internet-facing applications
- reducing risk from common web exploits and bot abuse
- protecting upstream services from traffic spikes and attacks

## when_not_to_use
- internal-only systems with no external exposure (still consider basic protections)
- when latency sensitivity cannot tolerate inline inspection and no bypass exists

## decision_signals
- need: internet-facing applications
- need: reducing risk from common web exploits and bot abuse
- willing to accept: false positives can block legitimate users

## advantages
- reduces attack surface and improves availability
- provides centralized security controls and logging

## disadvantages
- false positives can block legitimate users
- requires ongoing tuning and rule management

## anti_patterns
- using this when internal-only systems with no external exposure (still consider basic protections)
- use this when latency sensitivity cannot tolerate inline inspection and no bypass exists
- ignoring the downside that false positives can block legitimate users

## real_world_examples
- blocking sql injection patterns and abusive ip ranges at the edge
- using rate-based rules to mitigate bot scraping
