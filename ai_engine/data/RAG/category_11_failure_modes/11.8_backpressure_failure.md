# Backpressure Failure


## chunk_id
- 11.8

## category
- failure_modes

## type
- failure_mode

## definition
- a condition where producers continue sending work faster than consumers can process, causing buffers, queues, or memory to grow until failure.

## when_to_use
- streaming systems and message brokers
- diagnosing queue growth, consumer lag, and memory pressure
- designing flow control between services

## when_not_to_use
- systems with inherently bounded workloads and no queues
- purely synchronous workflows with strict request limits

## decision_signals
- need: streaming systems and message brokers
- need: diagnosing queue growth, consumer lag, and memory pressure
- willing to accept: can lead to out-of-memory, disk full, or massive latency

## advantages
- motivates explicit flow control, shedding, and rate limits
- improves stability under overload by keeping queues bounded

## disadvantages
- can lead to out-of-memory, disk full, or massive latency
- recovery can be slow due to backlog drain time

## anti_patterns
- using this when systems with inherently bounded workloads and no queues
- using this when purely synchronous workflows with strict request limits
- ignoring the downside that can lead to out-of-memory, disk full, or massive latency

## real_world_examples
- downstream database slows and event backlog grows for hours
- consumers crash-loop while backlog continues to increase
