# Slow Query Degradation


## chunk_id
- 11.7

## category
- failure_modes

## type
- failure_mode

## definition
- a performance failure where one or more slow queries consume resources, increase contention, and degrade overall system latency.

## when_to_use
- diagnosing tail latency spikes and timeouts
- systems with shared database connections and limited pools
- evaluating indexing and query plan stability

## when_not_to_use
- purely in-memory systems with no shared query engine
- workloads with strict precomputed read models and bounded queries

## decision_signals
- need: diagnosing tail latency spikes and timeouts
- need: systems with shared database connections and limited pools
- willing to accept: can exhaust pools and cause widespread request failures

## advantages
- drives adoption of query timeouts, indexes, and read replicas
- helps prioritize workload isolation and capacity controls

## disadvantages
- can exhaust pools and cause widespread request failures
- can be intermittent due to plan changes and data growth

## anti_patterns
- using this when purely in-memory systems with no shared query engine
- using this when workloads with strict precomputed read models and bounded queries
- ignoring the downside that can exhaust pools and cause widespread request failures

## real_world_examples
- a missing index causes table scans during peak traffic
- a dashboard query runs in production and starves transactional workloads
