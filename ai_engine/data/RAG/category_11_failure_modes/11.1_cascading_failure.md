# Cascading Failure


## chunk_id
- 11.1

## category
- failure_modes

## type
- failure_mode

## definition
- a failure that propagates through dependencies, causing an initially small fault to amplify into widespread outage.

## when_to_use
- analyzing resilience of systems with many synchronous calls
- designing timeouts, retries, and circuit breakers
- evaluating blast radius and dependency criticality

## when_not_to_use
- single-component systems with no external dependencies
- fully offline batch workflows with isolated stages

## decision_signals
- need: analyzing resilience of systems with many synchronous calls
- need: designing timeouts, retries, and circuit breakers
- willing to accept: can cause rapid, unpredictable outage expansion

## advantages
- clarifies where to add bulkheads, fallbacks, and load shedding
- helps prioritize dependency hardening and isolation

## disadvantages
- can cause rapid, unpredictable outage expansion
- recovery may require coordinated restarts and traffic shaping

## anti_patterns
- using this when single-component systems with no external dependencies
- using this when fully offline batch workflows with isolated stages
- ignoring the downside that can cause rapid, unpredictable outage expansion

## real_world_examples
- a slow database causes api timeouts, retries increase load, and queues back up
- an auth service outage makes all downstream services fail closed
