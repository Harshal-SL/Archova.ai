# Dropbox File Storage System

## chunk_id
- 10.19


## category
- real_world_systems

## type
- real_world_system

## definition
- a file sync and sharing system that stores blobs, tracks metadata versions, supports sharing permissions, and syncs across devices.

## when_to_use
- designing object storage + metadata separation for file systems
- supporting offline sync and conflict resolution
- implementing secure sharing and link-based access

## when_not_to_use
- simple file uploads without sync or sharing requirements
- systems where versioning and auditability are unnecessary

## decision_signals
- file blobs are large and must be served via object storage/cdn
- metadata requires versioning and conflict resolution across devices
- sharing permissions must be enforced consistently on all access paths

## advantages
- blob/metadata separation improves scalability and cost control
- versioning supports recovery and audit of changes

## disadvantages
- sync conflict resolution is complex for offline clients
- permissions bugs can lead to severe data leaks

## anti_patterns
- serving file downloads through the metadata database path
- granting share links without revocation and auditing
- storing blobs and metadata together without independent scaling

## real_world_examples
- pre-signed urls for uploads/downloads with short expiry
- metadata versioning and sync tokens for clients
