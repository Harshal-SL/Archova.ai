# Cloudflare Edge Network

## chunk_id
- 10.10


## category
- real_world_systems

## type
- real_world_system

## definition
- an edge network that accelerates and protects internet traffic using global points of presence, caching, routing, and security filtering.

## when_to_use
- designing edge caching and request filtering close to users
- protecting origins with ddos mitigation and waf policies
- reducing latency for globally distributed web traffic

## when_not_to_use
- internal-only systems with no public traffic
- workloads that are fully uncacheable and do not benefit from edge compute

## decision_signals
- global users with latency sensitivity (<100ms edge target)
- high request volume requiring origin protection and rate limiting
- cacheability of assets and responses enables >80% offload

## advantages
- reduces origin load and improves performance via caching and routing
- adds security controls at the perimeter with centralized policies

## disadvantages
- cache invalidation and edge config drift require discipline
- debugging edge behavior can be harder than origin-only systems

## anti_patterns
- relying on edge caching without defining invalidation strategy
- pushing sensitive personalization to edge without access control
- using edge rules as a substitute for application-level security

## real_world_examples
- caching static assets and serving tls termination at edge
- blocking abusive traffic with waf rules and rate limits
