# Instagram Photo Sharing

## chunk_id
- 10.12


## category
- real_world_systems

## type
- real_world_system

## definition
- a media sharing platform that supports uploads, feeds, stories, search, and interactions with heavy use of object storage and cdn.

## when_to_use
- designing media upload pipelines with resizing/transcoding
- building personalized feeds with caching and ranking
- enforcing privacy controls and abuse prevention at scale

## when_not_to_use
- apps with no media pipeline requirements
- small-scale communities without heavy read traffic

## decision_signals
- media uploads require async processing and durable job queues
- global delivery requires cdn cache hit targets (>80%)
- feed latency targets (<200ms) with high fan-out

## advantages
- object storage + cdn provide scalable media distribution
- projections can separate interaction writes from feed reads

## disadvantages
- media processing pipelines can be expensive and failure-prone
- abuse and privacy enforcement require strong tooling and audits

## anti_patterns
- storing original media files in primary databases
- making uploads synchronous on all processing steps
- mixing permission checks inconsistently across feeds and media urls

## real_world_examples
- pre-signed uploads to object storage and async resizing workers
- personalized feed generated from follow graph and engagement signals
