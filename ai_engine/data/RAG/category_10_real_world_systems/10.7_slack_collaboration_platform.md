# Slack Collaboration Platform

## chunk_id
- 10.7


## category
- real_world_systems

## type
- real_world_system

## definition
- a team collaboration system combining real-time messaging, search, presence, permissions, and integrations at enterprise scale.

## when_to_use
- building multi-workspace chat with role-based permissions and retention
- supporting integrations via webhooks and event subscriptions
- designing search across messages/files with permission filtering

## when_not_to_use
- simple chat without enterprise permissions or integrations
- systems where search and history are not required

## decision_signals
- high concurrency with channel-based fan-out and presence state
- compliance requirements for retention, eDiscovery, and audit logs
- multi-tenant isolation with per-workspace policies

## advantages
- event-driven integrations enable extensibility without tight coupling
- strong permission model supports enterprise use cases

## disadvantages
- permission-aware search and history adds significant complexity
- fan-out and presence require careful state and cost control

## anti_patterns
- indexing messages without permission filters or audit controls
- coupling integrations to synchronous message delivery paths
- storing presence indefinitely without expiry and cleanup

## real_world_examples
- message events feeding a search index with access control
- integration platform emitting events for bots and external systems
