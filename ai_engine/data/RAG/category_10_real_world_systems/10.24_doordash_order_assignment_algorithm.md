# DoorDash Order Assignment Algorithm

## chunk_id
- 10.24


## category
- real_world_systems

## type
- real_world_system

## definition
- an assignment system that matches orders to dashers using proximity, prep-time predictions, batching opportunities, and acceptance probability.

## when_to_use
- food logistics systems balancing speed, quality, and utilization
- dispatch needing continuous re-optimization as state changes
- marketplaces where assignment quality directly affects margins

## when_not_to_use
- simple one-to-one routing with static schedules
- systems without real-time courier location and status updates

## decision_signals
- need: dispatch needing continuous re-optimization as state changes
- need: marketplaces where assignment quality directly affects margins
- willing to accept: algorithmic complexity and fairness tradeoffs

## advantages
- improves delivery time and courier utilization
- supports batching and route-aware assignment decisions

## disadvantages
- algorithmic complexity and fairness tradeoffs
- inaccurate prep-time estimates can degrade assignment quality

## anti_patterns
- optimizing only shortest distance and ignoring prep-time variance
- assigning before validating courier capacity and route feasibility
- lacking fallback strategy during dispatch service degradation

## real_world_examples
- hybrid score combining eta, bundle fit, and acceptance likelihood
- periodic rebalancing of pending orders during demand spikes
