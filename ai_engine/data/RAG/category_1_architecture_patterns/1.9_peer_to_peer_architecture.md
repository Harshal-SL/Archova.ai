# Peer-to-Peer Architecture


## chunk_id
- 1.9

## category
- architecture_patterns

## type
- architecture

## definition
- A decentralized architecture where nodes communicate directly without a central server.

## when_to_use
- decentralized systems
- blockchain applications
- file sharing systems

## when_not_to_use
- systems requiring centralized control

## decision_signals
- need: decentralized systems
- need: blockchain applications
- willing to accept: security challenges

## advantages
- high fault tolerance
- scalable node network
- decentralized

## disadvantages
- security challenges
- coordination complexity

## anti_patterns
- using this when systems requiring centralized control
- ignoring the downside that security challenges

## real_world_examples
- BitTorrent
- blockchain networks
