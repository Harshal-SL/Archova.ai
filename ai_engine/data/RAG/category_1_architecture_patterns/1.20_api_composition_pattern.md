# API Composition Pattern


## chunk_id
- 1.20

## category
- architecture_patterns

## type
- pattern

## definition
- A pattern where data from multiple services is combined at the API level.

## when_to_use
- microservices systems
- composite APIs

## when_not_to_use
- simple APIs

## decision_signals
- need: microservices systems
- need: composite APIs
- willing to accept: increased latency

## advantages
- flexible data composition
- reduces client complexity

## disadvantages
- increased latency
- coordination complexity

## anti_patterns
- using this when simple APIs
- ignoring the downside that increased latency

## real_world_examples
- dashboard APIs
