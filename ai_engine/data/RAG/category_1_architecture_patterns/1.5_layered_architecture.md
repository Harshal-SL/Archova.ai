# Layered Architecture


## chunk_id
- 1.5

## category
- architecture_patterns

## type
- architecture

## definition
- An architecture that divides the system into layers such as presentation, business logic, and data access.

## when_to_use
- enterprise applications
- structured business systems
- maintainable applications

## when_not_to_use
- high performance systems
- distributed architectures

## decision_signals
- need: enterprise applications
- need: structured business systems
- willing to accept: increased latency

## advantages
- clear separation of concerns
- maintainability
- easy debugging

## disadvantages
- increased latency
- rigid structure

## anti_patterns
- using this when high performance systems
- using this when distributed architectures
- ignoring the downside that increased latency

## real_world_examples
- Spring applications
- enterprise systems
