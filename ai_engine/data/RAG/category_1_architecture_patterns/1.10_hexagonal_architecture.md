# Hexagonal Architecture


## chunk_id
- 1.10

## category
- architecture_patterns

## type
- architecture

## definition
- An architecture that isolates business logic from external systems using ports and adapters.

## when_to_use
- domain-driven systems
- highly testable applications
- maintainable systems

## when_not_to_use
- very small applications
- simple systems

## decision_signals
- need: domain-driven systems
- need: highly testable applications
- willing to accept: complexity

## advantages
- strong separation of concerns
- high testability
- flexibility

## disadvantages
- complexity
- learning curve

## anti_patterns
- using this when very small applications
- using this when simple systems
- ignoring the downside that complexity

## real_world_examples
- DDD systems
- enterprise applications
