# Single Page Application Architecture


## chunk_id
- 1.22

## category
- architecture_patterns

## type
- architecture

## definition
- A frontend architecture where a single HTML page dynamically updates content without full page reloads.

## when_to_use
- modern web apps
- interactive UI

## when_not_to_use
- SEO-heavy applications

## decision_signals
- need: modern web apps
- need: interactive UI
- willing to accept: sEO challenges

## advantages
- better user experience
- fast interactions

## disadvantages
- SEO challenges
- initial load time

## anti_patterns
- using this when sEO-heavy applications
- ignoring the downside that sEO challenges

## real_world_examples
- Gmail
- Facebook
