# Serverless Architecture


## chunk_id
- 1.6

## category
- architecture_patterns

## type
- architecture

## definition
- A cloud-native architecture where code runs in stateless functions without managing servers.

## when_to_use
- event driven workloads
- low to medium traffic systems
- rapid development

## when_not_to_use
- long running tasks
- high performance systems

## decision_signals
- need: event driven workloads
- need: low to medium traffic systems
- willing to accept: cold start latency

## advantages
- automatic scaling
- no server management
- cost efficient

## disadvantages
- cold start latency
- limited control
- vendor lock-in

## anti_patterns
- using this when long running tasks
- using this when high performance systems
- ignoring the downside that cold start latency

## real_world_examples
- AWS Lambda apps
- Firebase apps
