# Modular Monolith Architecture


## chunk_id
- 1.2

## category
- architecture_patterns

## type
- architecture

## definition
- A monolithic system structured into well-defined modules with strict boundaries but deployed as a single unit.

## when_to_use
- medium scale applications
- systems transitioning toward microservices
- teams needing modular separation without complexity

## when_not_to_use
- very small applications
- systems needing independent deployments

## decision_signals
- need: medium scale applications
- need: systems transitioning toward microservices
- willing to accept: still a single deployment unit

## advantages
- better structure than monolith
- easier to refactor into microservices
- lower complexity than distributed systems

## disadvantages
- still a single deployment unit
- scaling limitations
- risk of module coupling

## anti_patterns
- using this when very small applications
- using this when systems needing independent deployments
- ignoring the downside that still a single deployment unit

## real_world_examples
- Shopify (early architecture)
