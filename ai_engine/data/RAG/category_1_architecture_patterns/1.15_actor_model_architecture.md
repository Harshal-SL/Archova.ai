# Actor Model Architecture


## chunk_id
- 1.15

## category
- architecture_patterns

## type
- architecture

## definition
- A concurrency model where independent actors communicate via message passing.

## when_to_use
- highly concurrent systems
- real-time systems
- distributed systems

## when_not_to_use
- simple applications
- low concurrency systems

## decision_signals
- need: highly concurrent systems
- need: real-time systems
- willing to accept: complex debugging

## advantages
- scalability
- fault isolation
- concurrency handling

## disadvantages
- complex debugging
- message coordination overhead

## anti_patterns
- using this when simple applications
- using this when low concurrency systems
- ignoring the downside that complex debugging

## real_world_examples
- WhatsApp (Erlang)
- Akka systems
