# Isomorphic / Universal Rendering Architecture


## chunk_id
- 1.24

## category
- architecture_patterns

## type
- architecture

## definition
- A rendering approach where code runs on both server and client.

## when_to_use
- SEO critical apps
- fast initial load

## when_not_to_use
- simple frontend apps

## decision_signals
- need: sEO critical apps
- need: fast initial load
- willing to accept: complexity

## advantages
- better SEO
- improved performance

## disadvantages
- complexity

## anti_patterns
- using this when simple frontend apps
- ignoring the downside that complexity

## real_world_examples
- Next.js apps
