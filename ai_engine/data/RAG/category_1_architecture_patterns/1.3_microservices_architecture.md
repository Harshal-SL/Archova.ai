# Microservices Architecture


## chunk_id
- 1.3

## category
- architecture_patterns

## type
- architecture

## definition
- An architecture where an application is composed of multiple independent services communicating via APIs.

## when_to_use
- large scale systems
- independent service scaling required
- multiple development teams
- frequent deployments

## when_not_to_use
- small applications
- early stage startups
- simple workflows

## decision_signals
- need: large scale systems
- need: independent service scaling required
- willing to accept: operational complexity

## advantages
- independent scaling
- fault isolation
- flexible technology stack
- faster deployments

## disadvantages
- operational complexity
- network latency
- distributed system failures
- complex debugging

## anti_patterns
- using this when small applications
- using this when early stage startups
- ignoring the downside that operational complexity

## real_world_examples
- Netflix
- Amazon
- Uber
