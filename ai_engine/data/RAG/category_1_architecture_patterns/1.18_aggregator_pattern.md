# Aggregator Pattern


## chunk_id
- 1.18

## category
- architecture_patterns

## type
- pattern

## definition
- A pattern that combines responses from multiple services into a single response.

## when_to_use
- microservices architecture
- composite data responses
- API aggregation

## when_not_to_use
- single service systems

## decision_signals
- need: microservices architecture
- need: composite data responses
- willing to accept: added latency

## advantages
- reduces client calls
- simplifies API usage

## disadvantages
- added latency
- complexity in aggregation

## anti_patterns
- using this when single service systems
- ignoring the downside that added latency

## real_world_examples
- e-commerce dashboards
