# Saga Pattern


## chunk_id
- 1.13

## category
- architecture_patterns

## type
- pattern

## definition
- A pattern used to manage distributed transactions through a sequence of local transactions with compensation steps.

## when_to_use
- microservices architecture
- distributed transactions
- long-running workflows

## when_not_to_use
- monolithic systems
- simple transactions

## decision_signals
- need: microservices architecture
- need: distributed transactions
- willing to accept: complex coordination

## advantages
- avoids distributed locking
- improves scalability
- fault tolerance

## disadvantages
- complex coordination
- difficult debugging

## anti_patterns
- using this when monolithic systems
- using this when simple transactions
- ignoring the downside that complex coordination

## real_world_examples
- order processing systems
- payment workflows
